# Canify

Canify is an iOS application designed to organize and play personal concert recordings by artist and song. The app provides a structured media library, video playback, and synchronized lyrics for a more interactive concert-viewing experience.

## Features

* Browse concert recordings by artist
* View songs associated with each artist
* Play concert videos directly inside the app
* Display synchronized lyrics during video playback
* Automatically highlight the current lyric line
* Navigate through artists, songs, videos, and lyrics with a multi-screen interface
* Custom table view cells for artist and song lists
* Support for local video and lyric files

## Technologies

* UIKit
* AVFoundation
* AVKit
* AVPlayer
* UITableView
* Storyboards
* Auto Layout
* Xcode
